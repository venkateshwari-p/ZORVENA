# ZORVENA Showcase Website

A responsive, static one-page showcase website for ZORVENA. It uses the supplied logo and requires no backend, database, paid hosting, or build tools.

## Preview locally
Open `index.html` in a browser.

## Free hosting options

### GitHub Pages
1. Create a GitHub repository (for example, `zorvena-website`).
2. Upload `index.html` and the `assets` folder, keeping the folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your public website URL after deployment.

### Netlify
1. Open Netlify and sign in.
2. Choose **Add new site → Deploy manually**.
3. Drag the complete `zorvena-showcase` folder (or its ZIP contents) into the deploy area.
4. Netlify will publish it and provide a free `*.netlify.app` URL.

## Customization
- Edit text and layout in `index.html`.
- Replace `assets/zorvena-logo.png` with an updated logo using the same filename.
- This is a static informational showcase; contact forms, user accounts, and server-side features are not included.
