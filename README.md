The `extracted/zorvena-showcase/` directory is the preserved source package; the live site is published from the repository root.

## Updating the website

1. Open this repository on GitHub.
2. Select `index.html` to edit text or page sections, or `styles.css` to adjust the design.
3. Use the pencil icon, make the change, and commit it to the `main` branch.
4. Open the **Actions** tab and check **Deploy ZORVENA website to GitHub Pages**.
5. Wait until the latest run shows a green check mark, then refresh the live website.

Changes to the published site are deployed automatically when the relevant website files are updated on `main`.

## Hosting

The website is hosted using GitHub Pages. No separate hosting server is required for this static website.
